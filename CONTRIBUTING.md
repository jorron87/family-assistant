# Contributing

Use Windows and Node.js24+, run `npm ci`, `npm run setup` and tests against an isolated data directory. Keep the source services mocked in automated tests. Add targeted regression coverage for changed parser, identity, lease, task, publishing or refresh behavior.

Do not submit production exports, screenshots with real children, school documents, personal IDs or credentials. Recreate the behavior using synthetic fixtures. Configuration and setup changes must work for a different number of family members and different names. Preserve canonical IDs, checkmarks, visibility and receipt history when changing data contracts.

The application is Norwegian-first and Windows-hosted. Contributions toward portability, new municipal/activity adapters, reliable source change detection and lower agent cost are welcome. Keep optional integrations opt-in and document unsupported assumptions. Run `npm run privacy-check` and review all staged files before opening a PR.
