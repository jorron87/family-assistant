# Mobilinnboks

Se docs/setup.md for lokal tilgang og HTTPS-tunnel. Domene og familielenker opprettes av din installasjon. Åpne /phone-setup lokalt, lag invitasjon og knytt hver telefon til riktig person. Bruk Send inn til ren tekst, bilder eller PDF. Avsender og innsendingstid brukes til jeg/min og relative datoer. Agenten behandler ferdige innsendinger når egen lease er ledig. Uferdig opplasting behandles aldri.

Legg til siden på hjemskjermen i Safari/Chrome. En separat nettleserøkt må eventuelt knyttes til på nytt. Invitasjonen utløper etter24 timer; en telefonøkt varer inntil seks måneder og kan tilbakekalles. Hold lenkene private.

HEIC: installer eget Python-miljø med config/phone-image-requirements.txt og kjør python scripts/phone-image.py ORIGINAL OUTPUT_STEM.png. Les alle eksporterte bilderammer og bevar originalen. PDF-er leses fullstendig, visuelt ved behov. En uleselig fil skal være blocked med konkret grunn.

Rett lokal event på samme canonicalKey før Calendar, kvitter gjeldende fingerprint og kontroller dashboardet. Done med kalenderendringer krever alle lokale eventIds. Profilvurdering og privat publisering kreves også. Se runbook.
